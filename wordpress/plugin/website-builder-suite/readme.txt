== Description ==

O Website Builder Suite é um construtor de sites visual, low-code, gratuito e de código aberto que exporta temas de blocos para o WordPress. Este plugin adiciona:

* **Formulário de contato que funciona**: envia por e-mail (wp_mail) e guarda cada mensagem em "Mensagens" no painel, com proteção anti-spam (campo armadilha + nonce).
* **Seções em modo livre**: exibe as seções com posicionamento livre criadas no app.
* **Prévia dos blocos** dentro do editor do WordPress.

Sem o plugin, o tema continua exibindo o conteúdo; apenas o envio dos formulários depende dele.
